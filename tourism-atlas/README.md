# ATLAS — Інтерактивний туристичний атлас світу

Україномовний навчальний сайт для спеціальності **J3 «Туризм та рекреація»**. Версія 1.0 (листопад 2026).

## Можливості

- Інтерактивна SVG-карта світу з масштабуванням, панорамуванням і вибором країн.
- **78 країн, 303 туристичні пам'ятки** (добірка, а не вичерпний світовий реєстр).
- Пошук за країною, столицею, регіоном і назвою пам'ятки, фільтри за частинами світу.
- Фотографії пам'яток, автоматично отримувані з відкритого API Вікіпедії, з посиланнями на сторінки авторства і ліцензій у Wikimedia Commons.
- Геоквест на 12 випадкових запитань з автоматичною оцінкою за 12-бальною шкалою.
- Конструктор маршруту до шести зупинок, навчальні місії й прогрес.
- PDF-звіт за допомогою стандартного друку браузера (вибрати «Зберегти як PDF»).
- Адаптивна верстка для смартфонів і комп'ютерів, без реєстрації та серверної бази даних.

## Запуск локально

Виконай у папці проєкту:

```bash
python3 -m http.server 8000
```

Потім відкрий http://localhost:8000 . Відкривати `index.html` через `file://` без сервера не рекомендується, оскільки браузер може блокувати `fetch()` локальних JSON-файлів.

## Розміщення на GitHub Pages

1. Створи **новий публічний репозиторій** `tourism-atlas` у GitHub.
2. Завантаж у корінь `index.html`, `style.css`, `app.js`, `countries.json`, `world-shapes.json` і порожній `.nojekyll`.
3. У **Settings → Pages → Build and deployment → Deploy from a branch** обери `main` і `/ (root)`; натисни Save.
4. Адреса сайту буде `https://ІМʼЯ-КОРИСТУВАЧА.github.io/tourism-atlas/` після успішного розгортання.

**Якщо сайт завантажено як окрему папку `tourism-atlas` у вже опублікованому репозиторії**, шлях: `https://ІМʼЯ-КОРИСТУВАЧА.github.io/НАЗВА-РЕПОЗИТОРІЮ/tourism-atlas/`.

## Для викладача

Рекомендована практична робота: дослідити п'ять країн, обрати по пам'ятці з трьох країн, сформувати маршрут, пройти геоквест, зберегти звіт у PDF і надіслати його до Google Classroom. Можна застосовувати власні критерії для оцінювання маршруту; результат квізу оцінюється окремо за 12-бальною шкалою.

## Джерела та ліцензії

- Геометрія карти: **Natural Earth** / naturalearthdata.com, public domain (взята з копії набору Natural Earth lowres, що постачається для тестування `pyogrio`, зі спрощенням контурів).
- Фотографії карток завантажуються під час перегляду з **Wikipedia / Wikimedia Commons**. Автор, джерело та ліцензія беруться з опису кожного файлу; посилання з'являється поверх фотографії. Вимоги можуть відрізнятися для кожного фото. Якщо недоступний API, показано кольоровий фон.
- Герой-фото: **Unsplash**; посилання на провайдера — внизу сайту.
- Назви туристичних об'єктів і короткі описи — редакційна навчальна добірка, не офіційний список об'єктів ЮНЕСКО.

**Увага**: сайт не надає цін, графіків роботи, рекомендацій щодо безпеки, візових правил або актуальної доступності пам'яток. Для реальних поїздок перевіряти офіційні джерела.

## Технічна структура

- `index.html`: контент і семантична розмітка.
- `style.css`: адаптивний дизайн, друк PDF.
- `app.js`: інтерактивність, квест, маршрут, джерела фото.
- `countries.json`: каталог країн і пам'яток — легко доповнювати.
- `world-shapes.json`: шляхи SVG для карти.

Прогрес відвідування, маршрут та результат квесту зберігаються лише локально в браузері (`localStorage`). Оцінювання не має серверної перевірки та може бути змінене через налаштування браузера; для формального контролю викладач перевіряє PDF-звіт і виконання завдання.
