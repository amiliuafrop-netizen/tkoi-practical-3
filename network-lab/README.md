# NETWORK LAB — навчальна віртуальна лабораторія

Україномовний інтерактивний сайт з дисципліни **«Вступ до спеціальності»** для спеціальності **172 «Електронні комунікації та радіотехніка»**.

## Можливості

- **8 модулів**: LAN, маршрутизація, IP/CIDR, OSI/TCP-IP, DNS/DHCP/NAT, діагностика, GPON/FTTx, 5G.
- **Повноцінний інтерактивний мережевий стенд**: додавання та перетягування вузлів, створення/редагування Ethernet, fiber, wireless з’єднань, живлення портів, параметри IP/маска/шлюз/DNS, змодельовані DHCP/DNS/NAT.
- Діагностика: неправильний кабель, вимкнений канал, некоректні адреси, конфлікт IP, недосяжний шлюз, відсутня маршрутизація, перевищення портів, неправильна довжина мідного кабелю, недостатній оптичний запас.
- Пояснення помилок та **конкретні підказки для виправлення** з кнопкою переходу до потрібного пристрою/кабелю.
- Модельний Ping із текстовим журналом та фізичним шляхом.
- Теоретичні матеріали, словник термінів, RFC та ITU-T джерела.
- Візуальне пояснення OSI, IP-підмережний калькулятор.
- GPON-калькулятор оптичного бюджету з розкладом втрат.
- 5G-планувальник умовного покриття з перетягуванням базових станцій.
- Геоквест/тест: 12 випадкових питань із банку 30, автоматична оцінка за 12-бальною шкалою й пояснення після кожного запитання.
- Відстеження завершення місій у localStorage, друк навчального звіту (**Друк → Зберегти як PDF**) з ПІБ та групою.

## Як запустити

Усі 5 файлів (`index.html`, `styles.css`, `data.js`, `engine.js`, `app.js`) треба розмістити в **одній папці**. Відкрийте `index.html` у браузері; локальний сервер не потрібен.

Для GitHub Pages: завантажте папку `network-lab` у репозиторій, у якому увімкнено GitHub Pages на гілці `main`. Публічний шлях матиме вигляд `https://OWNER.github.io/REPO/network-lab/`.

## Обмеження та академічне застереження

Це **дидактичний симулятор**, а не справжній емулятор протоколів або заміна Cisco Packet Tracer / GNS3. Фізична зв’язність, IPv4, ICMP, DHCP, DNS і NAT спрощені; довільні топології можуть виходити за межі підтримуваної логіки. У GPON використовуються навчальні оцінки втрат та умовний резерв 3 дБ. У 5G Planner радіозони геометричні, без фізики поширення, SINR та перешкод. Оцінки й прогрес зберігаються лише в браузері та не проходять серверної перевірки — для офіційного контролю викладач перевіряє виконання та звіт.

- IETF RFC 1918 (приватні адреси): https://www.rfc-editor.org/rfc/rfc1918
- IETF RFC 4632 (CIDR): https://www.rfc-editor.org/rfc/rfc4632
- IETF RFC 2131 (DHCP): https://www.rfc-editor.org/rfc/rfc2131
- IETF RFC 1034 (DNS): https://www.rfc-editor.org/rfc/rfc1034
- ITU-T G.984.1 (GPON): https://www.itu.int/ITU-T/recommendations/rec.aspx?rec=9379
- 3GPP (5G): https://www.3gpp.org/technologies/5g-system-overview

## Технічна структура

`index.html` — оболонка; `styles.css` — оформлення й друк; `data.js` — курси, сценарії та банк питань; `engine.js` — перевірки; `app.js` — інтерфейс і взаємодії. Зовнішні Javascript-бібліотеки не використовуються; шрифти завантажуються з Google Fonts, з системним fallback.
