# NETWORK LAB START — Мережі простими словами

Оновлена проста версія мережевої лабораторії для студентів-початківців із дисципліни **«Вступ до спеціальності»** (спеціальність 172 «Електронні комунікації та радіотехніка»).

## Основні зміни
- Немає складного редактора на головному екрані — лише 8 зрозумілих уроків із коротким поясненням, завданням, перевіркою та конкретною підказкою.
- Помилки не блокують навчання: студент може повторювати вправу без обмежень.
- Теми: локальна мережа, маршрутизатор, IPv4, інкапсуляція TCP/IP, DNS/DHCP/NAT, пошук несправностей, GPON, 5G.
- 10 контрольних запитань, результат у 12-бальній шкалі й пояснення до хибних відповідей.
- Введення імені та групи, звіт для збереження через **Друк → Зберегти як PDF**.
- Прогрес зберігається локально в браузері. Серверної бази даних немає.
- Попередня докладна версія доступна за шляхом `advanced/` і не використовується за замовчуванням.

## Розгортання
Для GitHub Pages папка `network-lab` повинна містити `index.html`, `styles.css`, `app.js`, а в `advanced/` — файли старої лабораторії. Усі файли автономні, JavaScript не потребує серверного API. Відкривати `index.html` можна без локального сервера.

## Важливо
Це **навчальна імітація**, а не фізична емуляція обладнання Cisco, справжнього TCP/IP, GPON або 5G. Результат тесту та виконання уроків зберігаються в `localStorage` і можуть бути змінені у браузері; для формального оцінювання викладач перевіряє звіт і виконання завдань.
